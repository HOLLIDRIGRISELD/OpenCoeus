# Audit 20 Fixes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix all 20 findings from the 2026-11-23 audit with TDD regressions.

**Architecture:** Four parallel slices with strictly disjoint file ownership: persistence/safety, organisation, analysis engine, naming/UX. Main session integrates and runs full verification.

**Tech Stack:** Python 3.11, PySide6, SQLAlchemy, pytest, ruff.

**Spec:** `docs/superpowers/specs/2026-11-23-audit-20-fixes-design.md`

## Global Constraints

- No new dependencies. No `OPENCOEUS_WRITE_GOLDEN`. No wholesale golden regeneration.
- Do not edit user data, config files or DB files.
- Every risky branch gets a test written and watched failing before production code.
- Focused pytest + ruff per slice; main session runs full pytest, ruff, compileall, quality gate.

## Review Focus

- Restart persistence: GUI reopen keeps files/plans/history.
- Restore safety: incompatible backup cannot replace live DB; live app stopped before restore.
- File safety: rollback and failure recovery cannot strand or mis-point a file.
- Analysis speed: no N+1 record reads, no empty-hash duplicate lookup, no second full-file hash.
- Cancel: GUI thread stays responsive and worker actually stops.

### Task 1: Persistence and safety (findings 1, 5, 6, 8 backup name, 20)

**Files:** `app/ui/app.py`, `app/services/context.py`, `app/infrastructure/database.py`, `app/ui/pages/history.py`, `app/ui/main_window.py`, `app/services/recovery_service.py`, `app/cli.py`, `app/core/config.py`, `tests/test_audit_final_data.py` plus existing focused test files.

- GUI uses `AppContext.create(purge=False)`.
- Restore validates required columns (`PRAGMA table_info`) before replacing DB; GUI cancels tasks/disables main window and forces restart.
- Default backup name includes microseconds.
- CLI `profile delete` confirmation + `--yes`; manifest output refuses overwrite without `--yes`.
- `AppConfig._load_from()` validates types/ranges with key-specific `ConfigurationError`.

### Task 2: Organisation (findings 2, 3, 7, 8 root, 17, 18)

**Files:** `app/services/organisation_service.py`, `app/organisation/executor.py`, `app/organisation/planner.py`, `app/organisation/validator.py`, `app/organisation/recovery.py`, `tests/test_audit_final_org.py`.

- Rollback uses final path when holding path is gone.
- Failure recovery reverts DB location/index.
- Plan validation/revalidation use stored plan root.
- Root fallback uses `commonpath`.
- Conflict checks skip vacating sources; `execute()` recomputes conflicts.
- Undo resets suggestion status.

### Task 3: Analysis engine (findings 4, 9, 10, 11, 14, 16, 19)

**Files:** `app/services/analysis_service.py`, `app/infrastructure/repositories/analysis.py`, `app/infrastructure/repositories/files.py`, `app/infrastructure/repositories/caches.py`, `app/processing/hashing.py`, `app/services/scanning_service.py`, `app/intelligence/embeddings.py`, `app/intelligence/keywords.py`, `app/intelligence/summarisation.py`, `app/intelligence/llm.py`, `tests/test_quality_gate.py`, `tests/fixtures/quality_golden.json`, `tests/test_audit_final_analysis.py`.

- Batch projection replaces per-file `get_record()`; duplicate lookup skips falsy hashes and is grouped.
- Analysis reuses scan hash unless size/mtime changed.
- One nested transaction per batch; feature digests cached with IDF.
- `needs_review` persisted in `extra`; golden values updated deliberately.
- Validated LLM title/org/date copied into `DocumentProfile`.
- IDF corpus fingerprint added to model name only when corpus changes after first use (keeps golden stable).
- Failed LLM probe gets timestamp backoff.
- Golden compare drops exact suggestions and adds semantic checks.

### Task 4: Naming and UX (findings 12, 13, 15)

**Files:** `app/intelligence/content_naming.py`, `app/intelligence/entities.py`, `app/intelligence/naming_engine.py`, `app/core/progress.py`, `app/ui/base.py`, `app/ui/workers.py`, `app/ui/pages/search.py`, `app/services/search_service.py`, `app/search/semantic.py`, `app/search/hybrid.py`, `tests/test_audit_final_ux.py`.

- Entity ranking by source then length; full ISO dates; numeric prefix stripping.
- Grouped names use supported title; subtype hints limited; one dedup helper.
- `Task.cancel()` non-blocking; token reaches search worker; `OperationCancelled` re-raised.
